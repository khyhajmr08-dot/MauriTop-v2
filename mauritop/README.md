# MAURITOP / MAURIPAY

مشروع React/TypeScript + Firebase مع خادم Express في `server.ts`.

## ملاحظات مهمة قبل التشغيل

- هذه النسخة تحتوي تعديلات على صفحة الدفع، وإدارة الخدمات، ورفع الصور الشخصية، وقواعد Firebase، وصلاحيات الموظفين.
- ملفا `package-lock.json` و`bun.lock` لا يطابقان حالياً `package.json`. لم يتمكن بيئة المراجعة من تثبيت الاعتماديات، لذلك لم يُعتمد بناء الإنتاج بعد.
- `firebase.json` يهيئ استضافة ملفات `dist` فقط؛ مسارات `/api/*` تحتاج نشر خادم Node على خدمة تدعم Express وربط المسارات بها.
